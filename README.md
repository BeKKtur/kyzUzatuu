# Кыз Узатуу — статический сайт

Готовая страница находится в `site/dist/index.html`. Это обычные HTML, CSS и JavaScript: сборка, npm и серверные функции не требуются. Папка `dist` содержит исходные файлы сайта и должна храниться в Git, а не создаваться при деплое.

## Vercel

Импортируйте корневой репозиторий и выберите:

| Настройка | Значение |
| --- | --- |
| Root Directory | Корень репозитория (`.`), поле можно оставить пустым |
| Framework Preset | Other |
| Build Command | Пусто — включить Override и очистить поле |
| Output Directory | `site/dist` |
| Install Command | Пусто |

Корневой `vercel.json` фиксирует эти настройки. Если в проекте ранее был выбран Root Directory `site` или `site/dist`, замените его корнем репозитория. После отправки изменений в GitHub создайте новый deployment.

Vercel публикует **содержимое** `site/dist`: главная страница доступна по `/`, стили по `/styles/`, модули по `/components/`, изображения и шрифты по `/assets/`. Дополнительные rewrites не нужны: сайт одностраничный, навигация использует `#`-якоря.

## Локальный просмотр

Из корня проекта:

```sh
python3 -m http.server 4173 --directory site/dist
```

Откройте `http://localhost:4173/`. Не открывайте HTML через `file://`: браузеру нужен HTTP для JavaScript-модулей.

## Персонализация

Все клиентские данные: `site/dist/config.js`.

Структура компонентов и описание конверта: `site/README.md`.

## Исправление структуры Git

Раньше корневой репозиторий хранил `site` как gitlink без `.gitmodules`, поэтому обычный clone не получал файлы сайта. Теперь `site` — обычная папка с отслеживаемыми файлами. История бывшего вложенного репозитория сохранена локально в `.git/legacy-site-repository` и не входит в публикацию.
