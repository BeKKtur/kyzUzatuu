# Кыз Узатуу

Персонализация: **`dist/config.js`**. Для нового клиента меняйте только этот файл.

- `event`: имя, название, дата ISO с часовым поясом `+06:00`, отображаемые дата/день/время.
- `texts`: все тексты и подписи интерфейса.
- `venue`: название, адрес и прямая ссылка 2GIS.
- `program`: список пунктов программы.
- `images`: свои локальные изображения или HTTPS-ссылки. Пустой `petal` отключает лепестки.

Демонстрационные данные нужно заменить перед рассылкой. Зал на изображении — декоративная AI-иллюстрация, не фотография указанного заведения. 2GIS сейчас ведёт на поиск демонстрационного адреса.

## Простая структура

```
dist/
  config.js                 ← все данные клиента
  index.html                ← структура страницы
  app.js                    ← подключение компонентов
  components/
    content.js              ← заполнение страницы
    envelope.js             ← открытие конверта
    countdown.js            ← обратный отсчёт
    motion.js               ← появления, параллакс и лепестки
  styles/
    base.css                ← шрифты, цвета, общие элементы
    envelope.css            ← геометрия и слои конверта
    sections.css            ← секции и мобильная адаптация
  assets/                   ← локальные шрифты и изображения
```

Локальный просмотр: `python3 -m http.server 4173 --directory dist` из папки `site`.

## Как устроен конверт

Печать снимается → клапан поворачивается → клапан уходит назад → письмо поднимается через верхний край → письмо полностью выходит → появляется кнопка перехода.

Слои фиксированы: задняя стенка 1, открытый клапан 2, карман с письмом 3, боковые сгибы 5, передняя стенка 6, закрытый клапан 8, печать 10. Письмо **никогда** не получает слой выше передней стенки. Сам карман обрезает содержимое внизу. Не меняйте z-index письма при анимации.

Поддержаны клавиатура, повторное нажатие, reduced motion и часовой пояс Asia/Bishkek. Веб-сайт статический: сборка и установка зависимостей не нужны.
